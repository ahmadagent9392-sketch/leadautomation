# START HERE

## You only touch 2 files
- `START_HERE.md`: this guide
- `docs/MY_OFFER.md`: fill in your service, price and proof

Claude Code reads all the other files. You can ignore them.

## Start (4 steps)
1. Install **Git**, **Python 3.11+**, **Node.js 20+**. Run `claude update`.
2. Fill in `docs/MY_OFFER.md`.
3. Open **PowerShell** in this folder and run this once:
   ```
   Copy-Item -Recurse -Force claude-setup .claude
   ```
4. Run `git init`, then `claude`. Press **Shift+Tab** until you see **plan mode**.

## Every stage
Type this (change only the number):
```
Read CLAUDE.md, docs/PROGRESS.md and docs/ROADMAP.md. Do Stage 1 only. Explain everything to me in simple words.
```
Then:
1. Read the plan → say yes.
2. Test it yourself.
3. Save: `git add .` then `git commit -m "stage 1"`
4. Type `/clear` → next stage.

## Stages
0 Get ready · 1 Rules + offer · 2 Memory · 3 Research + proof · **4 Lead cards** ·
5 Messages + Gmail drafts · 6 Follow-ups · 7 Auto finding (HN, jobs, Google Maps, idea search) ·
7b LinkedIn file + paste/screenshot · **8 Dashboard + autopilot** · 9 Use + weekly report

## If something goes wrong
- **Esc**: stop Claude
- `/rewind`: undo recent changes
- Never turn on "skip permissions"
